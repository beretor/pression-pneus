# Pression Pneus

Calculateur de pression de pneus pour trois vélos (Gravel Van Rysel, Rockrider VTT, Canyon Endurace), basé sur le poids du cycliste, la saison/équipement, le montage tubeless ou tubetype, et les conditions (sec/mouillé).

## Utilisation

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur ce dépôt (Settings → Pages → Deploy from a branch → `main` / `root`) pour y accéder en ligne.

Aucune dépendance, aucun build : une seule page HTML autonome.
